# AI Project Memory

This directory is maintained automatically by DevSpace and the active coding agent.

## Core Documents

- `PROJECT.md`: stable project identity, architecture, environments, constraints, and durable preferences.
- `STATE.md`: authoritative current execution state and checkpoint anchor.
- `TASKS.md`: active tasks, acceptance criteria, evidence, dependencies, and backlog.
- `HANDOFF.md`: exact resume package for the next chat or agent.
- `LEARNINGS.md`: validated lessons, recurring mistakes, successful patterns, and gotchas.

## Progressive Artifacts

- `plans/`: dated implementation and investigation plans.
- `decisions/`: ADR-style decisions with alternatives and consequences.
- `sessions/`: concise material session records and legacy archives.
- `incidents/`: production failures, root causes, recovery, and prevention.
- `discoveries/`: non-obvious facts awaiting promotion into durable learnings.

Core documents and the active plan are loaded automatically. Other artifacts are read only when relevant.
