## Portfolio Cards (Grid):
Each card contains:
- **Image:** Gradient placeholder (300px height)
- **Category Badge:** Top-right corner
- **Title:** Project name
- **Description:** Brief description
- **Tags:** Technology/service tags
- **Result Box:** Shows achieved result (icon + value + label)
