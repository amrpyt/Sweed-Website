# Improve Home Hero Typography And Imagery

## Summary

Improve the homepage hero with verified local business imagery and calmer Arabic typography.

## Reason

The hero relied on one remote background image and overly heavy type. The brand surface needs real imagery, better typographic rhythm, and less generic AI-template weight while preserving SWEED identity.

## Scope

- Add three verified local business hero images with no women visible.
- Crossfade the hero images without JavaScript.
- Reduce excessive hero font weight and tighten the type scale.
- Keep CTA behavior, existing Arabic content, and route structure unchanged.

## Success Criteria

- Hero uses three local images from `/images/hero/`.
- Hero image shuffle respects reduced-motion preferences.
- Hero heading remains readable on mobile and desktop.
- Typecheck, lint, build, and browser smoke checks pass on port 3000.
